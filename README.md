# 📋 VeloTask - Modern Responsive Task Manager

> A modern, responsive task management application built with Flutter Web, featuring a clean dashboard UI, real-time state management, and a mobile-friendly experience.

![Flutter](https://img.shields.io/badge/Flutter-%2302569B.svg?style=for-the-badge&logo=Flutter&logoColor=white)
![Dart](https://img.shields.io/badge/dart-%230175C2.svg?style=for-the-badge&logo=dart&logoColor=white)
![Provider](https://img.shields.io/badge/State%20Management-Provider-blue?style=for-the-badge)

---

## ✨ Features

- Professional Material 3 Dashboard
- Responsive Desktop & Mobile Layout
- Add, Edit & Delete Tasks
- Mark Tasks as Completed
- Priority-based Task Management
- Real-time Filtering
- Input Validation
- Empty State UI
- Clean & Reusable Widgets

## 🚀 Getting Started

### Prerequisites

- Flutter SDK (Stable)
- Chrome or Edge
- Git

### Installation

```bash
git clone https://github.com/Mohit-Ahir/VeloTask.git
```

```bash
cd VeloTask
```

```bash
flutter pub get
```

```bash
flutter run -d chrome
```
